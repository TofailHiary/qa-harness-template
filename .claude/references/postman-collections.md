# Postman Collections (Reference)

> Only relevant if **Postman** is enabled (§2). Tool: `mcp__postman-api-mcp__*`.

## How to use
- Search existing elements: `searchPostmanElements` → drill in with `getCollection` /
  `getCollectionRequest` to get the exact request contract (URL, headers, body, auth).
- Prefer the collection's saved request as the contract when testing an endpoint, then cross-check the
  live response against the DB (§6) and the backend route (§9).
- The workspace / collection identifiers for this project: record them here during `/configure-project`.
